1. Primo Avvio (Creazione Admin Aziendale) e Gerarchia dei 3 Ruoli

Alla prima apertura di ML-ProxVision dopo l'installazione (http://IP-SERVER:3000), il database parte completamente pulito e senza utenti preimpostati. La schermata iniziale permette all'azienda che ha installato il programma di registrare il proprio Account Amministratore (Nome, Email aziendale, Password e Nome Azienda). Successivamente, dal menu ⚙️ Impostazioni & Info, l'Admin potrà creare liberamente gli account per i propri Supervisori e Tecnici:

Ruolo Chi lo crea Funzioni e Permessi Abilitati
👑 Admin Creato al Primo Avvio dall'azienda (o da un altro Admin) Controllo Totale: gestisce aziende, scarica gli agent, elimina aziende, crea/rimuove gli account Supervisore e Tecnico e personalizza il nome dell'azienda che ospita la dashboard nel menu Impostazioni.
🛡️ Supervisore Creato dall'Admin in ⚙️ Impostazioni Gestione Aziende & Installazione Agent: inserisce nuove aziende clienti, genera il codice API e scarica direttamente sotto al codice API il file proxmox-agent.sh già configurato.
🛠️ Tecnico Creato dall'Admin in ⚙️ Impostazioni Visione Dashboard & Soluzioni Problemi: consulta lo stato di aziende, nodi, VM in tempo reale e legge le procedure per risolvere i difetti, senza poter modificare impostazioni o aziende.

2. Menu "Dashboard Generica" e Grafici Interattivi per Azienda

La schermata iniziale mostra due grafici interattivi che sintetizzano lo stato di tutte le aziende registrate:

  • Grafico a Pizza / Ciambella (a sinistra): suddivide le aziende per stato di salute. Il valore 100% OK (verde) indica assenza di problemi; una percentuale di problematiche pari o superiore al 10% colora lo spicchio in giallo o rosso.
  • Mappa a Rettangoli (a destra): mostra un rettangolo per ciascuna azienda con barra bicolore (verde = funzionamento regolare, arancione/rosso = % problematiche) e l'anteprima dei difetti riscontrati.
  • Click Diretto: cliccando sullo spicchio della pizza, sul nome dell'azienda o sul rettangolo, si apre immediatamente la pagina dell'azienda posizionandosi sul riquadro #problematiche.

3. Menu "Aziende & Clienti" e Generazione File Agent Preconfigurato

Entrando nel menu 🏢 Aziende & Clienti (con profilo Admin o Supervisore):

  1. Mentre inserisci il Nome dell'Azienda nel modulo di sinistra, il programma genera in tempo reale il Codice API Key.
  2. Proprio sotto al Codice API compare il pulsante verde ⬇️ Scarica File Agent Già Configurato (proxmox-agent-nomeazienda.sh).
  3. Il file scaricato contiene già al suo interno la chiave API dell'azienda e l'indirizzo della dashboard: basta copiarlo sul nodo Proxmox e metterlo in cron!

💡 Come funziona se l'azienda ha un Cluster Proxmox (più nodi) o un PBS?
  • Cluster Proxmox: se i nodi Proxmox del cliente sono uniti in Cluster, ti basta installare il file .sh su UNO SOLO dei nodi! L'agente v5 interroga /nodes e invia in automatico i dati di tutti i nodi del cluster e di tutte le loro VM.
  • Proxmox Separati (Non in cluster): se un'azienda ha più server Proxmox indipendenti, installa lo stesso identico file .sh dell'azienda su ciascun Proxmox: la dashboard li raggrupperà tutti sotto la stessa azienda.
  • Proxmox Backup Server (PBS): viene rilevato in automatico leggendo gli storage del nodo Proxmox VE (senza dover installare nulla sul PBS).

5. Menu "Ticket & Allarmi", "Knowledge Base" e "Impostazioni & Info"

  • ⚠️ Ticket & Allarmi (/alerts): raccoglie tutti gli allarmi aperti con la diagnosi generata dall'AI Locale (Ollama). Con un click puoi segnare l'allarme come risolto e archiviarlo nella Knowledge Base.
  • 📚 Knowledge Base (/kb): archivio ricercabile di tutte le soluzioni tecniche e comandi Proxmox salvati dal team.
  • ⚙️ Impostazioni & Info (/settings): permette all'Admin di inserire liberamente il nome dell'azienda e del server su cui è montata la dashboard, gestire gli utenti/ruoli e visualizzare i crediti ufficiali dell'ideatore Mattia Leoni.

6. Procedura di Installazione su Ubuntu Server e Nodi Proxmox

A) Installazione della Centrale Dashboard sulla VM Ubuntu Server:

git clone https://github.com/mattyleo/proxmox-dashboard.git
cd proxmox-dashboard
chmod +x install.sh && sudo ./install.sh

B) Installazione dell'Agente su un Nodo Proxmox VE:

Scarica il file proxmox-agent-<azienda>.sh dalla pagina Aziende (sotto al codice API), copialo in /root/proxmox-agent.sh sul nodo Proxmox ed esegui:

chmod +x /root/proxmox-agent.sh
/root/proxmox-agent.sh
echo "*/2 * * * * root /root/proxmox-agent.sh >> /var/log/proxmox-agent.log 2>&1" > /etc/cron.d/proxmox-agent
